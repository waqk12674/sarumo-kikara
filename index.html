ざっくりな遊び方How to Play

～サルをつなげてハイスコアをねらおう！～~ Chain up monkeys for a high score! ~

  1. 右上からサルをドラッグ
  2. 以下の方法でサルを枝にひっかける
    ・枝の上で指を離す
    ・サルの体が赤くなるところで指を離す
  3. サルの下にもサルをひっかけられる
  4. 場所が気に入らなければひっかけ直す
  5. 得点がはいるのは新たなサルだけ
  6. サルが地面につくとゲームオーバー
  1. Drag a monkey from the top-right card
  2. Hook it onto a branch:
    ・let go right over a branch
    ・or let go where the monkey turns red
  3. Monkeys can hang from other monkeys, too
  4. Don't like the spot? Pick it up and hang it again
  5. Only newly added monkeys score points
  6. If any monkey touches the ground, it's game over
